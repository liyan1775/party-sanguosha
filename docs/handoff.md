# 开发交接

## 当前版本与提交基线

`package.json` 版本已升至 `1.1.1`（基于 `5794d2e` 之上收口本轮队友手牌与公开面板防闪烁、护栏检查及独立验收补修）。以后接手可用 `git log -2 --oneline --decorate`、`git rev-list -n 1 v1.1.1` 与 `node -p "require('./package.json').version"` 复核。

## 正式打开入口

| 手里的文件         | 从哪里打开                                                                                                                                                                                                                                   |
| ------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 源码仓库           | 在根目录双击 `启动聚会三国杀.cmd`。首次准备源码环境见[项目说明](../README.md#从源码运行验证与打包)。                                                                                                                                         |
| Windows x64 发行包 | 完整解压 `party-sanguosha-v1.1.1-windows-x64-setup.zip`，在解压目录双击 `无黑框启动聚会三国杀.vbs` 或 `启动聚会三国杀.cmd`。首次启动须联网取得并校验固定素材。[版本下载页](https://github.com/liyan1775/party-sanguosha/releases/tag/v1.1.1) |

电脑保持联机页 `/server` 开启。玩家用手机扫码开房或入座，开房的玩家担任房主。同 Wi-Fi 可用局域网码，异地朋友等公网码就绪。聚会结束双击 `停止聚会三国杀.cmd`，山河册和自定义将池保存在电脑上。

## 已验范围

### 独立验收补修

2v2 公开观战沿用选将台的红蓝队：1、4 号位为蓝队，2、3 号位为红队。身份局继续按原生亮明条件展示身份。队友牌条跟随询问的实际移动时间避让；远处的透明度动效不触发持续测量。记牌器双开时避开同桌队友牌，拥挤时优先保住确认区，换局从顶部打开，键盘收起后焦点回到开关。公开观战和本局记录复用分页按钮，迟到响应保留玩家当前焦点。

桌面 Edge 158 的真实斗地主中，1.5 秒询问于 825ms 后移动，原验收脚本的鼠标、触摸点击均命中；动画后静置 1106ms，牌条布局测量 0 次。真实 2v2 在 1280×720、固定 0.85 缩放下连续 60 帧纵坐标零跳动，确认栏与手牌最小净距 12.75px；自然对局另一次最后 60 帧也零跳动。真实十张队友牌与记牌器在 844×390 和 1280×720 均相隔 5px，重叠面积为零。观战、记录翻页的键盘焦点及记牌器换局归顶在真实浏览器的受控数据下验证。证据在 `.runtime/independent-fixes-20261126/`。

完整门禁 `npm run check` 通过，347 项测试全部通过、零跳过。桌面 Edge 全量浏览器回归 80/80 通过，耗时 11.4 分钟。源码、重建的 `dist` 与浏览器使用的副本通过构建指纹校验。原生 2v2、斗地主专项通过，高校联赛专项 7 项通过，覆盖真实发牌、候补观战、投降计分与下一局。另行重跑独立报告的 18px 开发者工具字号实验，撤销强制样式后贴边间距仍为 32.875px，该辅助断言预期约 6px，留待单独复核。实体手机、微信和 Windows 发行包双击未验。

### 工作区候选：队友手牌与公开面板

队友头像下的两种按钮文案共用占位。询问进入牌条附近才立即让出点击位置，远处询问改色只合并重算。房间观战后台刷新保留按钮文案，相同的公开牌桌和记录保留节点；投票倒计时独立更新。公开记牌器展开时读取最新快照，分类、最近明牌和最近动作分别更新。

桌面 Edge 的临界尺寸回归用同一组用例对照旧代码与候选：4 张牌／12px／1 倍与 10 张牌／16px／0.85 倍，旧代码两组都出现反复显隐，候选两组均连续 20 帧稳定且无待执行布局。固定引擎专项在斗地主和 2v2 真实选将发牌后验证了询问插入、显隐、确认首击、自动恢复、横滑至第 10 张及私有手牌隔离；2v2 另验证远处询问连续改色 10 次。上述触控验证来自桌面 Edge 模拟。

本轮在工作区运行 `npm run check` 通过（345 项单测，零跳过），并核对了当前源码指纹和构建产物。最终桌面 Edge 全套 77 项通过，新增的 6 项 DOM 回归在修复前的代码上均能报错。高校原生专项还验到实际发牌后的农民只读牌条、待命位公开观战、投票结算和下局衔接。本机验收记录在 `.runtime/hand-ui-regression-20261126/`。

### 既有版本记录

本次治理新增 `npm run check:garden`，已在真实工作区通过。带固定引擎的独立源码副本已跑通 `npm run check`，含护栏、类型检查、构建、345 项单测（零跳过）和格式检查。护栏单测用故意违规的输入验证逐项报错。采用独立副本是因为已有单测会在工作目录的 `.runtime` 创建临时文件。

- **桌面 Edge**：71 项浏览器回归通过。固定引擎实测覆盖斗地主叫分、选将、发牌与投掷，另有原生队友和《山河图》专项。小屏与横屏触控记录来自桌面模拟。

## 尚未验通的硬边界

- **实体手机微信**：此前收到扫码建房、选将及看到首手牌的反馈。本版本仍待 iPhone 与安卓微信实测锁竖屏横握、队友牌滑到末张、技能确认、连掷与回房。
- **朋友独立 Windows 电脑**：仍待从本版本实际下载包完整解压、首次双击、资源补齐、出现双码并扫码打出首手牌的整条验收。
- **异地公网**：两家 Wi-Fi 或不同运营商下的延迟、超过 1000 ms RTT 时的操作与中断恢复仍待实体设备复测。临时公网入口与跨网直连受网络条件影响。

## 下一步焦点

复验本轮改动时，运行 `npm run test:browser`、`npm run engine:verify:team` 和 `npm run engine:verify:college-ui`。实体手机优先复核反馈玩家的屏幕比例，观察静置牌条、首次确认和恢复后横滑；观战时检查后台刷新不打断正在阅读的公开记录。

先按[试玩清单](beta-testing.md)在朋友的 Windows 电脑走完发行包首装，再让同桌与异地手机分别扫码。回填包版本、手机型号、网络、实际走到的一步和可复现问题。验收摘要写入本页，本机留存的截图和日志仅作补充。
