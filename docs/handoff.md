# 开发交接

最后更新：2026-10-03。

## 当前状态

M0 扫码房间底座已经实现。**当前不能进行真实三国杀对局。** 玩家扫码、入座、准备与房主设置可以运行；开始按钮因真实引擎未接入而关闭。

- 新手：标准；进阶：界限突破 + 阴 + 雷 + 神话再临 12 神将。
- 用户尚无既定引擎版本或扩展；由项目研究公开上游。

详情在 `product.md`；不要重复询问已经确定的项目方向。

## 已实现的边界

- `RoomStore` 管理公开大厅，不包含手牌、身份或游戏结算。
- 房主随机能力链接换取 HttpOnly cookie；手机玩家有独立 cookie；刷新保留席位。
- 切换配置撤销准备；满房拒绝新玩家；已有玩家仍可恢复席位。
- 最后一个 SSE 连接关闭后显示离线并撤销准备。
- `NonameAdapter.status().ready` 固定为 `false`。扩展目录为空，入口拒绝未经接入的扩展。
- `config/mode-rules.json` 与 `roster-presets.json` 记录产品要求，尚未应用到真实引擎。

## 引擎研究现场

检查上游 `libnoname/noname` 的 v1.11.6，commit 和发布包 SHA-256 在 `config/noname-candidate.json`。

下载并校验约 40 MB 核心包，解压到 `.local/noname/v1.11.6`。它缺少完整图片/音频资产；不能将目录存在视为接入完成。本次没有下载约 1.22 GB 完整包。

主要问题：普通房主端占一个席位；根路径导入映射；局域网 HTTP 与 JIT/Service Worker；单武将单挑的联机与胜负路径。证据和验证顺序见 `engine-investigation.md`。

## 启停与本地文件

- `npm start` 启动大厅，房主/玩家链接在终端及 `.runtime/session.json`。
- 本轮发现本机 3000 端口已被其他程序使用，已在被忽略的 `.env` 中设置 `PORT=3001`；没有终止其他程序。当前服务使用 3001，接续时以 `.runtime/session.json` 为准。
- `Ctrl+C` 结束自己启动的进程。不要根据端口批量终止其他进程。
- `.runtime/previews` 是浏览器验证截图；`.local/research` 是研究过程文件。
- 流程测试截图中的二维码指向测试地址；真实扫码应使用当前运行的房主页面。
- `npm run check` 为常规检查；流程或页面修改后运行 `npm run test:browser`。
- 工作区没有外部引擎的受版本管理副本，研究配置足以重新下载并校验核心包。
