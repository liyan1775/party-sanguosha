## 两项产品改动

| 入口             | 人数与流程                              | 将池及赛制                                                   |
| ---------------- | --------------------------------------- | ------------------------------------------------------------ |
| 原“三国杀斗地主” | 3人，先看候选→叫分定地主→选将→手气→单局 | 保留现有将池并增加高校将池；保留原聚会版候选数的方案见下文   |
| 新“高校联赛练习” | 4名报名成员、2队，每小局3人出场         | 固定高校将池；标准12局／抢20分或快速6局／抢10分，同分加赛1局 |

高校房间默认“标准：12局／抢20分”，房主可在整场开始前改为“快速：6局／抢10分”。快速模式是用户要求的练习变体，只缩短局数和目标分，叫分倍数、将池、选将、换将、手气及单局规则相同；满6局同分加赛第7局，标准赛满12局同分加赛第13局。开场冻结所选赛制，局间不能切换。

不另建三人练习入口，不增加16／25或单小局赛制选项。电脑仍只提供服务和规则执行，玩家手机上的房主参赛、设置两队和AI并开局。原2v2、身份、单挑的玩法保持既有设计。

### 原斗地主的叫分与选将

将当前随机定地主、直接发地主10／农民6候选，改为先看候选再竞价。为保留现有聚会版最终10／6规模，设计先给三人各6个不重复候选，定地主后仅给地主从剩余池再随机补4个。地主不能在叫分时提前看到那4个；农民保留原6个，补将不得抽走别人的候选。标准27将也能容纳18个初始候选＋4个补将。

暂采用“不叫、1、2、3倍”，随机先叫、一人一次且只能抬高、3倍结束、全不叫由先叫位1倍当地主。这是参照固定引擎已有三人竞价交互的聚会版方案；不是本届海选细则确认，也不切换到带专用牌堆和势力选将的“智斗三国”模式。候选数、叫分档位及牌堆说明在房间可查；选择高校将池不会把普通斗地主改成四人战队赛。

已开启的点将意向进入本人的初始6将，不保证身份，不允许绕过竞价；跨席重复意向继续由服务端处理。普通斗地主的AI各自叫分、选将，尚未定身份时不建立固定队友代理。继续原生出牌、4张起手、每席每小局最多3次手气、回房，并采用下述农民互看手牌；不加高校换将额度、整场计分或官方海选排名。

## 高校模式的小局及整场

本届明文规定12／20和同分加赛，6／10是用户新增的快速练习；以下四成员细则主要按同年OL战队赛推定继承。没有原始依据的交互参数明确作为练习约定，后续取得手册时在同一配置修正。

1. **固定队伍和报名位。** A队为1、3，B队为2、4；开场冻结4名成员、真人／AI类型、队伍、高校将池及标准／快速赛制。真人可与AI组队；至少1名真人，其余席位可全AI。报名位不同于当局地主、二号农民、三号农民的出场位。
2. **各发4将。** 从本局白名单无重复抽取16名，分别归属4个报名席位；候选保持私有。首局随机先叫位，其后每个已完成小局顺延一位。高校模式关闭大厅点将，避免改写固定候选范围。
3. **轮流叫分。** 暂提供不叫及1–4倍，只能高于当前叫分、一人一次、4倍提前结束；全不叫则先叫位1倍当地主。历史图明确出现4倍，但最高倍数及这些细交互仍是训练参数。真人只代理本队AI在它报名位轮到的那一次，不合并两个叫分机会。
4. **确定角色与候选。** 最高叫分席位为地主，其队友不另占出场位；对方两人为农民。地主保留自己4将，规则宿主从队友原4将随机抽2将，形成固定6将；两农民各保留自己4将。补将只抽一次，真人不能指定哪2张或把剩余2张再塞给地主。农民座次暂按从地主报名位向后循环遇到的先后确定，待细则复核。
5. **换将并锁将。** 暂约定身份与补将确定后才换将，每个出场报名席位最多2次、一次替换本席候选1名，候选数保持地主6／农民4。补入的2将也在地主合法替换范围内；消耗地主自己的额度。待命席额度不转移；真人代理AI时消耗AI的2次，不能合并成4次。新将从未分配、未换出的本局剩余池抽取，不能取得他席候选或本局刚换出的将。已锁定不能再换，超时保留已确认结果。这些具体时点及排除规则属于练习约定，不冒充官方换将卡规则。
6. **控制权、手气与发牌。** 三个出场位各4张起手，手气按同年OL战队赛说明每个出场席位每小局最多3次整手刷新，初次发牌不占次数。标准／快速相同，刷新或重连不补次数，代理也不增加份额；这继续属于本届未明文参数的继承规则。两名农民从首次发牌起可互看当前手牌，手气刷新后同步最新牌面。若AI队友为地主，待命真人先获得该地主的唯一人工控制权，代理手气并操作整局；本人报名位没有第四份手牌。其余未接管AI沿用原生决策。真人可用现有托管操作让原生AI代打。
7. **原生对局及结束。** 地主有飞扬、跋扈、强易；强易采用每小局对每个其他角色各一次、取得一张手牌再交还一张的版本。农民阵亡后另一农民补1张。正常全灭胜负；25轮限制、体力和牌堆等见参数表。发牌后的真实引擎确认才算小局进入对局。
8. **累计比分与下一局。** 胜队加本局倍数、负队不扣分；标准先达20分或打满12局，快速先达10分或打满6局。先达目标即结束；满局数未达目标时高分胜，同分加赛1局，先叫位照常顺延，加赛胜队赢整场。未结束则回原练习房，保留比分、队伍和下一先叫位，由房主开启下一小局。

例如标准赛第11局结束A队达到20分即结束；12局结束A18∶B17则A胜，17∶17时加赛。快速赛第5局已达到10分时结束；满6局仍未达10分则比较比分，同分加赛第7局。不能比较地主胜场或MVP。重复结算、刷新或再次打开结算页只记一次分。中断小局不计分、不增加已完成局数、不推进先叫位；若另起该局，必须明确旧局中断，不能声称恢复了同一牌局。

## 真人与AI同队的操作边界

代理仅适用于开场冻结的大厅AI席位。另一个真人的断线或托管不会把它变成AI队友；房主也不能代理对手AI。服务器按“谁操作、替谁操作、当前阶段”逐次验证，不由手机自行指定身份。

| 队伍与本局角色       | 叫分／换将／选将                                           | 打牌与私有视角                                                       |
| -------------------- | ---------------------------------------------------------- | -------------------------------------------------------------------- |
| 真人＋AI，真人为地主 | 真人先分别代理两席叫分；从真人自己的4＋AI随机补2中换／选   | 真人打自己的地主，AI待命；不用第二个出场位                           |
| 真人＋AI，AI为地主   | 真人代理AI叫分，从AI自己的4＋真人随机补2中换／选；用AI额度 | 真人默认接管AI地主的手气、出牌、响应、技能及私有选择；可切原生AI托管 |
| 真人＋AI，两席为农民 | 真人在两个独立面板分别从自己4／AI4中换／选，各2次额度      | 两名农民互看手牌；真人打自己的农民，AI仍自行操作另一农民             |

AI当地主的代理是用户明确要求的练习功能，不声称官方允许选手替另一位真人操作。报名者、地主身份和胜负归属不变，只把这一局AI席位的操作者绑定到本队待命真人。比如A1真人、A3为AI而A3叫到地主：仍按A3原4＋A1随机2形成6选1，A1不能改用自己的全部4将；选择后A1的手机进入A3地主视角，比分照常计给A队。

### 农民互看手牌

原斗地主与高校标准／快速赛均采用农民互看，真人与AI同队也适用。授权来自本小局的两名农民角色，从首次发牌起同步队友当前手牌，手气刷新、摸牌、失牌及重连后保持一致。界面作为队友手牌只读展示；查看不增加代打或手气代理权限，也不自动允许把队友手牌当作自己的材料，操作仍由原生合法选择及服务端归属验证决定。

仅向同局另一名农民定向发送牌面，地主、地主队友、电脑公开观战及普通大厅快照不获此权限；其他未公开候选、牌堆及技能私有区不随之开放。下一小局按新身份撤销并重建授权，不能因上局同为农民而继续看本局地主手牌。这是用户确认的练习规则，不把未取得的本届手册写成已证实允许互看。

### 手机上如何分别选两名农民

显示“你的农民：4选1”和“AI队友：4选1”两个独立选择区，各有换将剩余次数、已选及锁定状态。按本人→AI的顺序完成，已锁定的结果不因另一面板刷新或超时丢失；不能提供任意8选2再自行分配的入口。AI为地主时只显示它合法6将的选将区，并明确“替AI队友选将，本局由你操作地主”。待命真人的剩余候选不能继续操作。

### 无人工决策及超时

全AI队和超时未完成选择要能独立继续。选将调用本席合法候选上的原生选将AI；不能使用当前2v2的共享10将、任意分配两将逻辑。已选角色、重复和越界结果由宿主核验，非法结果重新进入同期限的合法选择或原生回退。

固定引擎没有完整四成员战队竞价AI，故自动叫分和换将由适配器提供固定训练策略，单列验证，不宣称原生已经支持或最优。初版拟用本席4将的最高原生通用评级决定愿叫上限：评级6／7／8／9分别对应1／2／3／4倍，低于6不叫；若上限不能超过当前叫分则不叫。普通斗地主将上限截到3倍。未收录评级采用原生默认值，不读取对手候选、未来补将、手牌或牌堆。自动换将只替换本席最低评级且低于6的候选，最多2次；候选都达标时不强制花完。该策略用于能连续练习，不能把通用评级当作斗地主胜率。

真人叫分超时记不叫；代理换将超时不再消耗额度；已锁定选择保留，其余由合法候选上的原生AI完成。本人和AI的换／选区共用该阶段原截止时间，不给代理额外一轮时长。代理人工控制地主时，断线、超时和主动托管沿用原生出牌回退；恢复仍回同一地主、同一未完成请求和原期限。人工接回只在宿主确认的选择边界生效；已由AI完成的动作不撤回、不重新问一次。

## 状态、权限与恢复的实施边界

大厅显示4名成员、队伍、AI及标准12／20或快速6／10，开场前全员准备，切换赛制需真人重新准备；整场中不能切赛制、换人、增删AI、改队或改将池。要调整先明确结束整场。每名真人仍能分享LAN／公网房间码，昵称使用`textContent`；不引入账号、收费卡、高校身份认证或其他网络服务。

整场与小局分别存储：整场记录所选赛制及冻结的局数／目标分、四报名成员、队伍、比分、已完成局数、下一先叫位和已记分小局ID；小局记录四人私有候选、各席换将／手气额度、竞价阶段和三出场位。由服务端冻结“报名成员→出场角色→当前操作者”的映射，不能把待命真人改成第四个引擎玩家或把AI改成真人报名位。高校整场留在原房中，普通回房不清比分；结束整场再建下一场才清累计。

**代理授权分赛前与打牌。** 赛前允许真人看到自己及所代理AI的合法候选并提交对应操作，不授予手牌视角。AI地主接管建立之后，当前真人操作者获得该地主的原生私有消息、牌引用、手气和技能选择授权；规则执行仍在电脑宿主。必须同时适配出站`privacy.js`、入站牌引用与请求归属验证、原生选择路由和重连恢复，不能只在前端显示AI手牌。该映射不允许读取农民手牌，也不把电脑服务页或玩家房主变成全知控制者。

农民互看以独立的同局角色关系授予只读牌面，不依赖AI代理或房主身份；出站过滤及恢复快照按接收农民和实际手牌所属者核验，不能使用全局公开牌标记或透传宿主全量状态实现。入站继续按实际操作者与当前原生请求检查，不因可见队友手牌就允许代出。发牌和每次手气后的共享视图、剩余次数与原期限须一同恢复。

每个出场角色同一时刻只有一个决策者。人工接管／托管由宿主原子切换并递增控制版本；旧页面、旧控制版本及AI迟到结果不能重复执行。每小局角色改变就撤销旧局代理；下一局当农民的真人不得继续收到上局AI地主的恢复快照。AI托管时绑定真人仍可看这一个所控地主的本人视角，接回待下个可接管选择边界；已执行选择不回滚。

刷新恢复原候选、补入两将、替换记录、各席剩余额度、已锁定选择、竞价进度、角色／操作者、比分及原期限；不重抽、不重补、不复活已过期请求。写消息绑定房间、整场ID、小局ID、阶段版本、被操作席位及控制版本，服务器按当前浏览器会话核验。真人断线、托管或房主转移不改变冻结队伍及AI类型。自然结算确认并按小局ID幂等记分；开始下一小局须再次得到真实选将／发牌确认，不以收到WebSocket或大厅状态当作可玩证据。

沿用内存保存和双网络入口边界：重启服务不承诺保存整场；LAN主页、素材和牌桌不依赖公网，公网中断保留原码。本轮设计不重启正式服务、不改已存在的对局。
