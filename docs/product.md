# 产品需求

更新日期：2026-10-03。本文记录已确定的产品目标；实现状态以 `handoff.md` 为准。

## 使用场景

聚会玩实体卡牌时洗牌麻烦、开局慢；使用商业客户端又需要下载、教学、武将解锁、加好友。目标是让朋友围坐在一起，电脑负责发牌、规则和联机，手机只需要打开网页即可完整参与对局。

游戏应完成选将、身份分配、洗牌、发牌、回合推进、技能交互和结算。玩家之间的交谈和聚会氛围留在线下。

## 已确认

| 项目     | 要求                                                        |
| -------- | ----------------------------------------------------------- |
| 部署     | 一台电脑提供局域网服务，不依赖云服务器                      |
| 网络     | 玩家连接同一个 Wi-Fi 或电脑热点；首版不支持手机流量跨网加入 |
| 接入     | 微信扫码进入普通网页，无需注册、微信授权、安装客户端        |
| 电脑职责 | 保持主控页开启，展示二维码，整局避免休眠；不占手机玩家席位  |
| 房主     | 在电脑主控页选择模式、人数、武将档、经过验证的扩展          |
| 对局界面 | 先复用无名杀界面，改进扫码、开局、手机操作                  |
| 引擎来源 | 用户无指定现有版本或扩展，由项目评估公开上游并固定版本      |
| 商业流程 | 不引入商城、付费解锁、好友系统或强制新手流程                |

## 首版模式

| 模式         | 人数 | 规则边界                                                             |
| ------------ | ---- | -------------------------------------------------------------------- |
| 经典身份局   | 5–8  | 主公、忠臣、反贼、内奸；基础身份规则                                 |
| 三国杀斗地主 | 3    | 地主对两名农民；地主体力上限增加 1，增加「飞扬」「跋扈」             |
| 2v2          | 4    | 两人一队；具体座次、选将、死亡奖励按接入版本的规则验证并在开局前说明 |
| 单挑         | 2    | 每人一名武将，一局定胜负；没有阵亡换将的车轮战                       |

三国杀斗地主不是扑克牌斗地主。无名杀有对应 `doudizhu` 实现，当前候选为 `normal` 变体、OL 版本「飞扬」。候选设置需实测后才能用于对局；不得默认加入额外地主/农民强化。

`config/mode-rules.json` 是上述规则的结构化记录，尚不是可直接传给无名杀的运行配置。

## 武将两档

- **新手档**：标准包。
- **进阶档**：界限突破 + 神话再临·阴 + 神话再临·雷 + 神话再临 12 神将。

12 神将明确为：神关羽、神吕蒙、神周瑜、神诸葛亮、神曹操、神吕布、神赵云、神司马懿、神刘备、神陆逊、神甘宁、神张辽。

进阶档仅启用阴、雷对应分组，不启用整个神话再临普通武将包。神将使用上述白名单。对应上游标识和档位配置见 `config/roster-presets.json`；引擎升级时必须重新检查标识、分组及技能版本。

## 基本流程

1. 电脑启动服务，打开房主页并选择模式、武将档和扩展。
2. 玩家接入同一个网络，扫码、输入昵称、入座。
3. 玩家准备，房主确认人数齐全后开局。
4. 手机进入无名杀对局界面；电脑主控继续运行。
5. 玩家完成对局，回到房间开下一局。

房主修改玩法后所有玩家重新准备。刷新或短暂断线后应恢复本人席位；真实游戏重连需要由引擎适配器处理，不能把大厅重进当成游戏重连。

## 验收目标

- 电脑不占玩家席位，能够容纳 8 部手机的身份局。
- 四种模式都完成选将、出牌、技能、胜负结算、返回房间和再次开局。
- 武将候选池严格符合选定档位，无法通过玩家菜单开启额外武将或扩展。
- Android 与 iPhone 的微信内置浏览器分别完成完整对局；转到系统浏览器可继续接入。
- 玩家只看见本人的手牌和已公开信息，大屏二维码页面不显示任何玩家私有信息。
- 聚会当天运行不需要访问互联网；所需引擎和图片、字体、音频资源提前准备。
- 出现房主关闭、断线或扩展加载失败时，页面给出明确、可恢复的状态。

上述均为完整可玩版本的目标，当前底座仅通过大厅流程验证。
