目标是验证朋友仅按说明就能组织一桌。后续使用v0.7.12 Windows x64完整测试包，记录ZIP旁`.sha256`的值；v0.7.11报告与新修复的结果分别记录。测试包目前用于受邀试用，公开资源分发依据仍待核对。

2026-10-14已收到安卓、iPhone和电脑浏览器的局域网真实游玩反馈，核心同桌体验得到用户认可。下一次优先复测两点：新手机控件“确定／取消”的间隔及选将、出牌、技能取消；另一台Windows首次启动超过20秒时仍能持续等待并最终打开服务页。其余组合按实际使用补充，无需为了填满表格重新执行已经玩过的组合。某旧Edge缺少飞行动画暂作为已知限制；公网真机仍待测。

请将观察结果发回项目主人。只需写失败发生在哪一步，不必自行修代码或配置环境。别发送 cookie、`.runtime/session.json`、完整浏览器存储或私人手牌；截图请遮住未公开信息和朋友昵称。

## 另一台 Windows 电脑

请一位未参与开发的朋友，使用 Windows x64 电脑按下面步骤操作。无需安装 Node.js、Git、Codex 或编辑配置。

1. 完整解压测试包到普通文件夹，双击「启动聚会三国杀.cmd」。首次校验可能需要几十秒，保留启动窗口并观察提示，最多等待两分钟。记录是否最终打开电脑服务页，以及局域网码／公网码出现或报错的情况。首次 Windows 防火墙询问时，允许可信家庭网络的入站连接。
2. 电脑保持联网、页面开启、避免休眠。手机扫码建房；电脑不应自动成为玩家或房主。
3. 再双击启动，确认使用同一个大厅；不要因为重复启动而丢失牌局。
4. 完成下面至少一局和同房第二局，再双击「停止聚会三国杀.cmd」。确认本项目停止，电脑其他程序照常运行。
5. 再次启动，确认需要重新建房及分享新公网码。重启会清空房间，这不是游戏存档恢复。

只测局域网时使用「启动局域网聚会三国杀.cmd」；两种启动共用一个实例，切换前先停止。公网暂时不可用时，同 Wi-Fi 玩家应仍能正常使用局域网码。

## 手机组合

可分几次玩，不必一次凑齐全部组合。先让 Android 和 iPhone 在同一桌，再覆盖异地玩家。AI 可补足席位；请记录每桌实际真人数。

| 手机    | 入口                             | 网络                 | 本轮结果 |
| ------- | -------------------------------- | -------------------- | -------- |
| Android | 微信                             | 同 Wi-Fi             | 待填写   |
| Android | 系统浏览器／Chrome               | 同 Wi-Fi             | 待填写   |
| iPhone  | 微信                             | 同 Wi-Fi             | 待填写   |
| iPhone  | Safari                           | 同 Wi-Fi             | 待填写   |
| Android | 微信或浏览器，注明其一           | 手机流量或异地 Wi-Fi | 待填写   |
| iPhone  | 微信，优先原先延迟高的两家 Wi-Fi | 异地网络             | 待填写   |

从微信切换系统浏览器，或从 LAN 切到公网地址，会得到另一浏览器会话；测试同席位恢复时请留在原浏览器和原入口。需要换入口时先离座或请房主移除旧席位。

## 每桌必走的流程

1. 扫电脑主页码、填写昵称建房；另一人扫手机上的房间码加入。房主设置自动保存，普通成员不能代替房主改设置或开局。
2. 选一个模式，补 AI，真人准备、开局。实际看到候选武将并选将，随后看到自己的起手牌，才算进入对局。
3. 至少亲自完成出牌、响应杀／闪、选择目标及确认各一次；观察文字是否清楚、按钮能否触及、公开牌是否显示正常。别人应看不到自己的暗手牌和未公开身份。
4. 手机切后台约30秒后回来，在原入口刷新一次；核对原座位、当前体力和手牌。断线超过缓冲时 AI 可能已经行动，应有提示；自动连接恢复不等于自动收回托管。
5. 体验声音、静音与音量；iPhone 微信锁竖屏时横着握手机，切换显示方向后能继续操作。记录看不清或误触的位置。
6. 正常结束一局，普通成员先回房、房主再回房，重新准备并开第二局。第二局无需清缓存或重开电脑服务。

四种模式分别至少完成一局：单挑2席、斗地主3席、2v2四席、身份局5–8席。基础标准27将与经典进阶96将都至少用一桌；首轮不要求逐个验证所有官方将池或技能。

另在一局选将时刷新，核对仍是原候选，已选者不重弹，期限不重新开始。等待大厅中房主离线超过60秒后，在线成员应能显式接任；大家散场关页后，等待／已结算房间应在服务端确认全员离线约10分钟后收回。手机后台 TCP 释放和公网在线租约会影响开始计时的时刻，请记录实际现象。

## 网络与定向复测

LAN／公网混合同桌时记录每位玩家工具条的线路和往返延迟，不以动画速度推算网络速度。优先复测此前 iPhone 微信跨两家 Wi-Fi 超过1000ms的组合，并记下出牌是否明显等待、返回前台能否恢复。

在方便的局域网牌局中，可临时让电脑断开互联网、保留家庭路由器和局域网：LAN 玩家应能继续操作，新 LAN 玩家仍能打开主页／素材，电脑原公网码保留并标明中断。恢复联网后，再试原公网码。若不能安全保留局域网，可跳过并注明，不必为测试修改路由器。

用户此前遇到的两项可在自然出现时补测：借刀杀人先选两人、取消第一目标再重新选人，不能把无武器者提升为第一目标；刘璋宗护刷新牌桌后应仍交足当轮所需牌，再进入杀／闪选择。不要为了强行遇到这些技能反复重开或手动改牌堆。
