研究日期：2026-10-11；运行映射更新于2026-10-12。已从三国杀移动版官网公开下载的客户端配置恢复 **326 项完整时光场目录**，并用公开视频与官网社区原图交叉核对。完整官方 ID、名称、分类、技能名及来源哈希见 [机读研究名录](../config/research/mobile-time-field-2026-10.json)。已按用户要求新增独立运行将池：258项对应固定无名杀完整原生版本，68项仍有非主公技能差异，具体ID及原因见 [将池核对](official-rosters.md)。

## 完整目录的配置依据

来源为 [移动版官网](https://www.sanguosha.cn/)的[公开安卓包 sgs460.apk](https://download.sanguosha.cn/sgswx/sgs460.apk)。只读取 ZIP 索引及必要资产，离线解析配置与字节码，没有安装、运行或登录客户端。持久 JSON 保存了资产路径、长度、MD5/SHA-256 和原始成员哈希，可在官网包更新后辨别研究版本。

- `happyfight.lua` 的 `sectionData[7]` 明确命名「时光场」，内含固定使用 2020 年及以前非重制武将的说明；与录像中的规则页一致。
- `ModeCfg[58].SectionS[7]` 绑定 `RuleId=70`、`chrPoolType=17`、`gameEx={1,4,5,10,22}`；`ChrCfgData` 的 `id=70` 命名「斗地主怀旧场2020」，显式列出 211 个 `enableChrList` ID。
- 原生 `GameModeData:getJiangChiDataByGameEx` 先收集基础扩展集合，再并入规则名单，按官方 ID 去重；211 项不能单独当作完整目录。基础集合 309 项，与规则列表重合 16 项，合并为 504 项；将池 UI 按第 17 类规则过滤，其中 178 项是目录排除的 `ExType=22`。最后 **309 + 211 − 16 − 178 = 326**。
- 目录分为八类：**神话再临 75、界限突破 54、一将成名 56、界一将成名 12、乱世英杰 14、SP 97、神将 9、稀有专属 9**。合计 326，官方 ID 与名称均无重复。前六分类分母已由原生游戏画面直接复核，后两分类来自同版 UI 分类配置；没有用“差额 18”猜补名单。
- 自定义 ECC2 容器的长度与存储载荷 CRC、配置包 MD5、解封后 ZIP 全部成员 CRC 均通过。326 名均找到角色元数据；技能信息取同版 `CharacterData.Spell` 与 `SpellData.Name`，可获得技能另列，保留个别未具名技能 ID 的记录。

## 研究过程与可恢复材料

初期官网活动公告、公开社区搜索及介绍视频没有直接给出逐名全表，先保存了 326 总数、六分类分母、78 名彩色子集。随后读取官网 APK 的公开资产，定位 ECC2 脚本容器与同配置版本的加载信息，成功解封 13 个配置包、466 个成员；按原生规则合并与 UI 分类过滤恢复 326 名录。原先“解码未成功”“六分类差额 18 待查”属于已完成的中间阶段，当前结论以完整名录与上述核验为准。

官网社区可通过公开只读接口 `GET https://wxforum.sanguosha.cn/api/searchV2/topics?page=1&category_id=&keyword=时光场&is_theme=0` 获取帖子正文和原图链接。研究过程已保存相关检索结果、公开视频元数据和有时码的帧。旧的明文 `assets/data/character.xml` 含离线/旧模式条目，未作为时光场全表；`data.bin` 解析为 39 块 PNG，也未作为将池数据。

过程文件位于被忽略的 `.local/research/mobile-time-field-2026-10-11/`。持久研究名录保存完整 ID、名称、分类、技能、计数公式、资产哈希与公开来源；本文保留可读的完整名字和交叉核验证据。公开视频临时媒体 CDN 地址会过期，持久文档使用视频页面与社区原图链接。
