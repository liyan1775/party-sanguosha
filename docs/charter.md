# 聚会三国杀 · 项目北极星

本页只保留跨月不变的核心锚点与单向门取舍（上限 60 行）。细节需求查 [产品需求](product.md)，工程实现查 [架构与决策](architecture.md)，当前进度与未验边界查 [开发交接](handoff.md)。

## 第一性原理

- **本质痛点**：线下或熟人聚会玩实体三国杀洗牌慢、开局烦；商业客户端要下载、注册、加好友、走教学和氪金解锁。
- **核心解法**：**一台电脑双击开服执行权威规则与原生 AI，朋友手机扫码零安装、零账号、零商业流程直接开一桌**，同 Wi-Fi 直连兜底，异地公网码可同桌混玩。
- **体验基石**：直接复用固定版本无名杀的权威规则、原生牌桌交互与最强可用原生 AI，把精力花在「熟人开桌顺滑、手机好点、信息隔离严谨」上，而不是重造一套半成品三国杀。

## 明确不做（Non-Goals）

- **不做商业化与账号体系**：不引入登录注册、好友关系、商城、氪金解锁、强制新手教程或手机端安装包。
- **不把电脑变成参赛房主**：电脑只做规则宿主、二维码入口与公开观战控制台，不占玩家席位，也不拿玩家房主权。
- **不追求长期托管云服与跨重启续局**：默认面向本机即开即玩；不主动建云部署、持久域名或承诺服务重启后恢复进行中的内存牌局（仅 `data/shanhetu` 与 `data/rosters` 持久保存）。
- **不以牺牲局域网体验换公网功能**：公网中断绝不阻断同 Wi-Fi 聚会；不靠隐藏或篡改延迟数字制造流畅假象。
- **不读系统「减少动态效果」自动阉割动效**：默认完整动效，仅由玩家在应用内主动切换精简动效。

## 单向门决策备忘（Why）

- **回归固定无名杀原生牌桌，放弃自制轻量牌桌（2026-10-06）**：自制轻量渲染长期追不上海量武将技能与复杂询问交互；固定上游 v1.11.6 commit + `privacy.js` 过滤 + 贴身适配，既保完整技能又防上游更新炸服（禁止启动时追最新）。
- **原生 AI 固定最强可用、不设智力档位（2026-10）**：只放慢行动节奏方便看牌，不削弱 AI 决策、不另造低智机器人，保证混编补位对局质量。
- **自定义将池只组合已审查原生 ID、继承原规则档（2026-11-04）**：满足熟人自由组池，同时守住不自行改技、不放开未审包、不破坏平衡与安全的底线。
- **允许非主公技能一致时的异名与额外主公技，但不自行拼装或改写技能（2026-10-12）**：兼顾官方活动将池覆盖率与原生规则可信度。
