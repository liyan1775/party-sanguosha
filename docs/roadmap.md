# 开发路线

按实际可验证结果推进，未估算排期。完成状态以 `handoff.md` 为准。

## M0：项目底座和扫码房间

- [x] Git、目录边界、接续说明、忽略运行时文件。
- [x] 记录玩法、人数、单武将单挑、两档武将范围。
- [x] 房主页面、局域网地址选择、二维码、昵称入座、准备、席位恢复。
- [x] 服务端权限、满房约束、配置变更后撤销准备、断线状态。
- [x] 引擎研究候选与可验证的适配器边界。
- [ ] 手机微信实测扫码入座。

验收：电脑和多个独立浏览器会话能加入同一房间，电脑不占大厅席位。开局拒绝未就绪引擎，不提供假对局。

## M1：最小真实对局

- [ ] 选定可在局域网浏览器运行、可固定版本的无名杀基线。
- [ ] 下载/校验、所需资源、预编译、同源 HTTP/WebSocket 接入。
- [ ] 电脑规则主机不占任何手机玩家席位。
- [ ] 单武将单挑：从扫码到选将、出牌、胜负、回房再开局。
- [ ] 大厅与引擎身份绑定、行动权限、私有信息检查、游戏断线重连。

验收：一台电脑和两部手机完成真实单挑；关闭网络后恢复本人席位；所有资源由电脑提供。

## M2：四种玩法与两档武将

- [ ] 三国杀斗地主地主 +1 体力上限、飞扬、跋扈；不引入额外强化。
- [ ] 2v2 完整选将、座次、死亡奖励、团队胜负。
- [ ] 5、6、7、8 人身份局，确认电脑不占人数。
- [ ] 两档选将池生效且不能由玩家额外开启武将。
- [ ] 神将白名单、阴雷分组、各模式特殊限制验证。
- [ ] Android 微信与 iPhone 微信分别完成四种玩法，覆盖横竖屏、后台恢复。

验收：四种模式完整对局并可再次开局；进阶档不混入其他神将或整个风火林山普通包。

## M3：扩展与聚会交付

- [ ] 扩展 manifest、版本、引擎范围、浏览器/联机兼容检查。
- [ ] 电脑统一分发扩展及资源，所有手机保持版本一致。
- [ ] 房主开局前启用扩展；运行中锁定；加载失败可恢复。
- [ ] Windows 一键启动/离线准备、端口和防火墙诊断、可携带安装包。
- [ ] 开局速度和资源大小测量；说明来源、许可证与升级方法。

验收：聚会当天无需联网安装，启动电脑后扫码进入即可；第三方开发者可按照文档增加一个真实扩展并验证联机。
