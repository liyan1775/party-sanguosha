[完整原生武将清单](noname-characters.md)按固定核心静态提取26个普通武将包、2563个原生版本，包含名称、原生ID、所属包、势力、体力、技能、上游参考强度。不同版本单独列出，隐藏/变身形态保留标记。挑战、国战等模式专用角色及另装扩展不在本次普通包范围。结构化数据为 `config/native-character-inventory.json`，复现命令 `npm run engine:update-inventory`。

包名来自同commit的 `game/package.js`，原生强度标记来自 `character/rank.js`。该标记是无名杀的一般参考，不能当作身份、斗地主、2v2、单挑的胜率结论。清单不会自动把新角色加入产品，素材及私有数据仍须按选定范围验证。

## 下一轮强度分池的依据

先由用户确定想使用的原生版本及包范围，再比较四模式的稳定收益、爆发、恢复、控场、辅助、条件限制和操作复杂度。同人物版本必须明确原生ID，不以“界”“OL”等名称前缀推断强弱。

当前四模式按档位使用标准108牌或标准加军争、去木牛流马的160牌，辅助/主公技在单挑的价值、群体收益在身份局的人数放大、农民和2v2的配合、地主加成均需分别考虑。可以把上游评分作为初筛，再核对原生技能与本项目环境；不能用修改数值来追求等强，不能把少量AI对局当作真人胜率。

任何因强弱拟移除的武将，先给出具体原生版本、受影响模式、机制理由和证据，由用户决定。本轮96将范围已按用户确认的标准扩充；后续强弱调整仍遵循此约定。
