# 本项目扩展

此目录用于本项目新增的武将、技能、卡牌或规则扩展。当前没有接入扩展，`config/extensions.json` 保持空列表。

未来每个扩展使用 `extensions/<id>/`，包含源码、必要资源、说明和 manifest，记录：

- 稳定的 id、名称、版本、作者、来源和许可证。
- 支持的引擎版本与游戏模式。
- 是否依赖 Node、文件系统或客户端专用 API。
- 浏览器与联机验证结果、资源列表及内容校验值。
- 与新手/进阶武将档的关系。

扩展只能在房主开局前启用。电脑统一提供代码与资源，不要求手机导入 zip。不能只给房主安装扩展而默认手机可用。

引擎验证完成前不提供一个看似可安装的假扩展示例。接入接口以 `packages/noname-adapter` 的最终实现为准。
